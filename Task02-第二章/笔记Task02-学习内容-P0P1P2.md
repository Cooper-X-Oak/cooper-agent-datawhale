## P0 朴素理解（时间轴：到底发生了什么）

```text
1950s-1980s：符号主义/规则时代
  -> 思路：把人的知识写成规则，让机器按规则推理
  -> 结果：在窄场景好用，但现实太复杂，规则写不完

1960s-1970s：早期对话与封闭世界成功案例
  -> ELIZA：靠模式匹配“看起来会聊天”
  -> SHRDLU：在受限积木世界里表现很强
  -> 启示：封闭环境可行，开放环境容易失效

1980s：心智社会提出协作视角
  -> 观点：智能不一定来自一个完美大脑，也可以来自很多小模块协作
  -> 影响：给后来的多智能体系统提供了思想基础

1990s-2010s：数据驱动学习成为主流
  -> 神经网络/统计学习：从“手写规则”转向“从数据学规律”
  -> 强化学习：通过试错+奖励，擅长序贯决策任务

2018-至今：预训练 + 大模型 + Agent 融合
  -> 预训练先学通用能力，再微调/对齐到具体任务
  -> Agent在模型外叠加工具、记忆、规划与反思
  -> 现状：不是单一路线胜出，而是多范式组合更实用
```

### 纠错后的一版简答（供你对照）

- 1）本质差异：符号主义靠人工写规则和知识库；数据驱动靠模型从数据中学习表示与策略。  
- 2）难维护原因：知识获取瓶颈 + 规则组合爆炸，导致系统脆弱且迭代成本高。  
- 3）ELIZA vs ChatGPT：规则模板 vs 参数化学习；窄域脚本 vs 开放域泛化；几乎无上下文建模 vs 强上下文建模。  
- 4）关系：都强调多单元协作与涌现；但现代 MAS 更强调角色、通信协议与任务编排的工程化实现。  
- 5）数据需求：监督学习吃标注/构造标签数据；强化学习吃交互轨迹+奖励信号（可含自我对弈）。  
- 6）预训练意义与风险：缓解手工构建知识库难题，但带来偏见、幻觉、时效与版权隐私等风险。
