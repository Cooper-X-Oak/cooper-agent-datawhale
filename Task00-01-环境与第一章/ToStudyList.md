  - 为便于截图，在程序退出前增加暂停逻辑
- TAO 循环理解：
  - `Thought`：分析任务、识别信息缺口并规划下一步
  - `Action`：调用工具或在信息充分时 `Finish`
  - `Observation`：接收工具反馈，进入下一轮推理

## 习题记录（第一章第3题）

- Workflow 优点：规则固定、可审计、稳定；缺点：灵活性不足。
- Agent 优点：能动态决策、处理复杂例外；缺点：可控性和稳定性挑战更大。
- 推荐方案 C：`Workflow + Agent + 人工兜底`。标准单走规则，异常单由 Agent 辅助分析并人工确认。
